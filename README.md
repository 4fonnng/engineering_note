# Engineering Notes｜工程學習筆記

這是一個使用 HTML、CSS、JavaScript 製作的繁體中文響應式靜態網站。

## 網站頁面
- `index.html`：首頁
- `pages/electronics.html`：電子學
- `pages/semiconductor-devices.html`：半導體元件
- `pages/circuits.html`：電路學
- `pages/electromagnetics.html`：電磁學
- `pages/resources.html`：學習資源

## 專案結構
```text
engineering-notes/
├── index.html
├── AGENTS.md
├── README.md
├── pages/
├── css/style.css
├── js/main.js
└── assets/images/
```

## 本機預覽
直接以瀏覽器開啟 `index.html` 即可預覽。若使用 VS Code，也可以使用 Live Server 等本機預覽工具。

## GitHub Pages 部署
將整個資料夾內容上傳至 GitHub Repository 的 `main` 分支根目錄，再到 Settings → Pages，選擇 Deploy from a branch、`main`、`/(root)` 並儲存。

## 修改規則
開始新增或修改內容前，請先閱讀 `AGENTS.md`，並延續既有的繁體中文、版面、導覽、命名與測試規範。
