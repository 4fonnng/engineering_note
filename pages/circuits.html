02 / CIRCUITS

電路學 Circuit Analysis

從基本電路定律，到電容、電感的暫態響應與交流電路分析。

首頁/電路學

本頁重點

KCL 與 KVLRC / RL 暫態交流阻抗解題流程

FOUNDATION 01

克希荷夫定律

KCL

電流定律

Σ I = 0

任一節點流入電流總和等於流出電流總和，來自電荷守恆。

KVL

電壓定律

Σ V = 0

沿封閉迴路繞行一圈，所有電壓升與降的代數和為零。

列方程式前先選定電流方向與繞行方向。若計算結果為負值，代表實際方向與原先假設相反，不代表計算一定錯誤。

TIME RESPONSE 02

RC 與 RL 暫態

一階 RC 或 RL 電路在切換後，電容電壓或電感電流會以指數形式接近新的穩態值。

GENERAL FIRST-ORDER RESPONSE
x(t) = x(∞) + [x(0⁺) − x(∞)]e−t/τ

x(t)：欲求的電壓或電流；x(0⁺)：切換後初值；x(∞)：最終值。

電路時間常數連續性條件
RCτ = ReqC電容電壓 vC 不會瞬間跳變
RLτ = L / Req電感電流 iL 不會瞬間跳變

Req 是從儲能元件端點看入、依題目切換狀態求得的等效電阻。獨立源歸零時，理想電壓源短路、理想電流源開路。

AC ANALYSIS 03

交流電路的阻抗

在正弦穩態分析中，可以使用複數阻抗表示元件對交流電流的阻礙。

元件阻抗 Z相位特性
電阻 RZR = R電壓與電流同相
電感 LZL = jωL電壓超前電流 90°
電容 CZC = 1/(jωC)電流超前電壓 90°

其中 j 是虛數單位（j² = −1），ω = 2πf 是角頻率，單位為 rad/s。

SOLVING STEPS

一階暫態題的解題流程

  1. 判斷切換前狀態：先求電容電壓或電感電流的初始值。
  2. 使用連續性：vC(0⁺)=vC(0⁻)，iL(0⁺)=iL(0⁻)。
  3. 求最終值：分析切換後 t → ∞ 的直流穩態電路。
  4. 求時間常數：依切換後電路求 Req，再算 τ。
  5. 代入通式：使用初值、最終值與時間常數寫出完整響應。
