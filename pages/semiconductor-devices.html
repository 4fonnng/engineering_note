04 / SEMICONDUCTOR DEVICES

半導體元件 Semiconductor Devices

從材料與摻雜開始，理解電子、電洞如何影響半導體的導電能力。

首頁/半導體元件

本頁重點

半導體材料 摻雜與 N/P 型 載子濃度 導電率 計算範例 常見觀念

FOUNDATION 01

什麼是半導體？

半導體的導電能力介於良導體與絕緣體之間，而且會受到溫度、光照及摻雜等因素影響。常見材料包含矽（Silicon）與鍺（Germanium），其中矽廣泛用於積體電路與各類半導體元件。

核心觀念

半導體的電流主要由兩種可移動載子形成：帶負電的電子（Electron）與可視為帶正電的電洞（Hole）。

本質半導體與摻雜半導體

本質半導體

未刻意摻雜

理想純半導體中，熱激發產生的電子與電洞成對出現，因此電子與電洞濃度相等。

摻雜半導體

加入少量雜質

加入施體或受體雜質，可讓某一種載子成為多數載子，改變材料的導電特性。

DOPING 02

摻雜與 N 型、P 型半導體

矽原子有四個價電子。摻入不同價電子數的雜質，可以改變自由電子或電洞的數量。摻雜不會把材料變成帶整體淨電荷的物體；在一般情況下，材料仍維持近似電中性。

類型常見摻雜原子主要提供的載子多數載子
N 型磷、砷等五價施體額外電子電子
P 型硼等三價受體電洞電洞
N 型

電子是多數載子

電子濃度通常高於電洞濃度；電洞仍存在，稱為少數載子。

P 型

電洞是多數載子

電洞濃度通常高於電子濃度；電子仍存在，稱為少數載子。

CARRIER CONCENTRATION 03

多數載子、少數載子與濃度關係

在熱平衡且可使用一般非簡併半導體近似時，電子濃度 n 與電洞濃度 p 會符合質量作用定律（Mass Action Law）：

MASS ACTION LAW
np = ni2

n：電子濃度（m−3）　p：電洞濃度（m−3）　ni：本質載子濃度（m−3）

本質半導體在熱平衡時 n = p = ni。對 N 型材料而言，若已知多數載子電子濃度 n，可用 p = ni2 / n 估算少數載子電洞濃度；P 型材料則可用相同關係式處理。

注意：載子濃度會隨材料、溫度及摻雜條件改變。使用公式前，需確認題目是否處於熱平衡，以及是否符合公式假設。

ELECTRICAL CONDUCTIVITY 04

半導體的導電率

電子與電洞在電場作用下都能形成電流。若已知兩種載子的濃度及遷移率，可以估算材料的導電率：

CONDUCTIVITY
σ = q(nμn + pμp)

σ：導電率（S/m）　q：基本電荷量（C）　n、p：電子與電洞濃度（m−3）

μn、μp：電子與電洞遷移率（m2/(V·s)）

導電率越大，表示材料在相同電場下越容易形成電流。電阻率（ρ）與導電率互為倒數：

RESISTIVITY
ρ = 1 / σ

ρ：電阻率（Ω·m），適用於均勻材料的基本材料參數描述。

WORKED EXAMPLE 05

導電率計算範例

題目：某 N 型半導體的電子濃度為 1.0 × 1021 m−3，電子遷移率為 0.14 m2/(V·s)。若少數載子的導電貢獻可忽略，估算導電率及電阻率。

已知條件

  • q = 1.602 × 10−19 C
  • n = 1.0 × 1021 m−3
  • μn = 0.14 m2/(V·s)
  • 忽略電洞的導電貢獻。

計算步驟

  1. 使用近似式：σ ≈ qnμn。
  2. 代入數值：σ ≈ (1.602 × 10−19)(1.0 × 1021)(0.14)。
  3. 求得導電率：σ ≈ 22.4 S/m。
  4. 計算電阻率：ρ = 1/σ ≈ 1/22.4 ≈ 0.0446 Ω·m。
答案

估算導電率約為 22.4 S/m，電阻率約為 0.0446 Ω·m。此結果建立在忽略少數載子導電貢獻的題目假設上。

CHECK YOURSELF

容易混淆的觀念

  • N 型的「N」代表電子為多數載子，不代表整塊材料帶負電。
  • P 型的多數載子是電洞；電洞是描述電子缺位的等效載子。
  • 多數載子與少數載子都存在，只是濃度不同。
  • 質量作用定律需確認熱平衡及適用的半導體近似條件。
  • 計算導電率時，濃度、遷移率與基本電荷量的單位必須一致。
